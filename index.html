TrueSkin プライバシーポリシー

本アプリ「TrueSkin」（以下「当サービス」）は、ユーザーのプライバシーを尊重し、取得する情報および利用目的を以下のとおり定めます。

取得する情報

当サービスでは、サービス提供に必要な範囲で、以下の情報を取得する場合があります。

  • メールアドレス、Apple ID または Google アカウントに関連する認証情報
  • カメラで撮影またはユーザーが選択した画像
  • AI解析結果
  • 端末情報、アプリの利用状況、エラー情報等のログ
  • アプリ内課金の有効状態など、サービス利用に必要な情報

カメラ・写真の利用について

当サービスは、画像解析機能を提供する目的で、ユーザーの明示的な操作によりカメラまたは写真ライブラリを使用します。バックグラウンドで撮影を行うことはありません。

顔写真および顔データの取り扱い

当サービスでは、ユーザーが撮影または選択した顔写真を、AIによる肌状態の解析のために使用します。

当サービスが扱う顔データは、ユーザーが任意に撮影または選択した通常の顔写真です。

当サービスは、Face ID、顔認証テンプレート、顔の特徴量、顔の形状データ、本人識別を目的とした生体情報を取得しません。

顔写真は、肌状態の解析、肌年齢や肌状態の推定、解析結果の表示、およびユーザーが自身の肌状態を記録・確認する目的のみに使用されます。

顔写真は、本人確認、顔認証、個人識別、広告、トラッキング、プロファイリングの目的では使用しません。

画像データおよび解析結果の取り扱い

撮影または選択された画像は、画像解析および結果表示の目的で使用されます。

当サービスは、ユーザーの顔写真を当サービスのサーバー上に保存しません。

顔写真およびAI解析結果は、アプリが管理する端末内データとして保存される場合があります。

顔写真は、解析処理完了後、当サービスのサーバー上には保持されません。

利用目的

  • ログイン・認証
  • AIによる肌状態の解析
  • 肌年齢や肌状態の推定
  • 解析結果の表示
  • ユーザーが自身の肌状態を記録・確認するための履歴機能の提供
  • アプリ内課金状態の確認
  • サービスの提供、維持、改善
  • 不正利用防止、障害対応、お問い合わせ対応

外部サービスの利用

当サービスでは、ログイン認証、ユーザー管理、課金状態の確認、画像解析等のために、Apple、Google、Google Gemini API、Amazon Web Services（AWS）等の外部サービスを利用する場合があります。

ユーザーが撮影または選択した顔写真は、AI解析結果を生成する目的で Google Gemini API に送信される場合があります。

Google Gemini API に送信される画像は、肌状態の解析結果を生成する目的でのみ使用されます。

顔写真は、広告、トラッキング、本人識別、顔認証の目的で第三者に提供されることはありません。

iOSアプリ内課金の決済処理は Apple App Store により行われます。当サービスの運営者は、クレジットカード番号などの決済情報を取得・保存しません。

第三者提供

法令に基づく場合を除き、ユーザーの個人情報を第三者に提供することはありません。

当サービスは、顔写真を第三者に販売、貸与、広告目的で共有することはありません。

データの保存期間

当サービスは、ユーザーの顔写真を当サービスのサーバー上に保持しません。

顔写真およびAI解析結果が端末内に保存される場合、それらはユーザーがアプリ内または端末上で削除するまで保持される場合があります。

アカウント情報、課金状態、ログ等のサービス提供に必要な情報は、サービス提供、障害対応、不正利用防止、お問い合わせ対応に必要な期間保持される場合があります。

アカウント削除

ユーザーは、アプリ内の設定画面またはお問い合わせにより、アカウント削除を依頼できます。削除方法の詳細は、アカウント削除ページに記載します。

注意事項

当サービスの解析結果は、日常的な美容およびスキンケアの参考情報として提供されるものであり、医療行為、診断、治療、疾病の検出、専門的な助言を目的としたものではありません。
